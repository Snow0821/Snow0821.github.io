## 이력 추가하기

`teaching`의 한 레코드는 기관·과정·역할 ID와 기간만 참조합니다. `end: null`은 현재 활동이며, 시작일과 종료일이 같으면 단일 기간으로 표시합니다. 날짜는 `2026` 또는 `2026-08` 형식을 사용합니다. 기존 과정의 여러 업체 이력은 같은 과정 ID를 참조하는 별도 레코드로 추가합니다.

학위와 자격은 서로 다른 배열입니다. 학위의 `field`가 전공, `degree`가 전체 학위명, `degreeShort`가 모바일 요약용 표기이며, `institution`은 학교명, `school`은 소속 단위를 포함한 정식 표기입니다.

항목 개수, 표시 연도 범위, 현재/이전 구분, 모바일의 최신 항목은 데이터에서 계산합니다. 번역 파일에 숫자나 이력을 복사할 필요가 없습니다. 번역은 일반 텍스트이며 필요한 줄바꿈에는 `\n`을 사용합니다. 논문 제목·저자는 영문, 학회명은 선택 언어에 맞춰 표시하고 BibTeX는 영문을 사용합니다.

### 현재 활동

`currentRoles`는 확인된 현재 역할만 모은 홈·CV의 별도 요약입니다. 연결된 교육 활동이 있는 역할은 `teaching` ID를 참조해 기관·시작월·종료월을 재사용하며, 엘리스 프리랜서 활동처럼 개별 과정과 기간이 다른 역할은 별도 기간을 기록합니다. `title`은 역할, 선택 항목 `context`는 과정 맥락이며 한·영을 함께 적습니다. 종료월(`end`)이 생긴 역할은 현재 활동 영역에서 자동으로 제외됩니다. 종료 예정월은 공유 원본의 `plannedEnd`에 기록하며, `end: null`을 유지해 진행 중으로 표시합니다. 현재 활동 요약은 예정 종료월까지의 기간만 표시하며, 세부 교육 경력은 종료 예정 안내를 유지합니다. 진행 중 상태와 예정 종료월은 공통 원본에서 보존합니다. 프리랜서 활동을 상근·연속 고용으로 표시하지 않고, 과정 수나 전체 경력 수에도 더하지 않습니다. 현재 활동은 모바일에서도 접지 않고 표시하며 기존 강의·경력 원본은 그대로 유지합니다.

### 사업·과정 중심 교육 이력

교육 이력은 홈·이력·CV 모두 `기간 | 프로그램·기관 | 대상·강의 내용` 세 열로 표시합니다. 기본 열 비율은 18:22:60이며, 가운데 열은 사업명을 강조하고 확인된 운영기관을 보조 정보로 표시합니다. 오른쪽 열은 학교·기업 등 교육 대상과 실제 과정명을 강조하고 역할·담당 내용을 함께 표시합니다. 교육 대상을 주관기관이나 계약 법인으로 표시하지 않습니다. 모바일에서는 열을 세로로 쌓고 각 열 이름과 접근성 표 구조를 유지합니다. 별도 사업명이 확인된 과정만 `courses[].program`을 기록하며, 사업명이 없으면 실제 과정명을 제목으로 사용합니다. 사업명이 같아도 기관·원본 사업 ID가 다르면 합치지 않습니다. 검증된 짧은 담당 내용은 `teaching[].summary`를 통해 홈·이력·CV에 함께 반영합니다.

### 학교·업체별 상세 이력

학교별 프로그램명이 확인된 과정은 `courses`의 `showSchoolPrograms`와 `family`, 상세 항목의 `programTitle`을 사용합니다. 웹은 기존 학교 항목에서 실제 프로그램명과 기간을 표시하고, CV는 기관·사업별로 실제 교육과 학교들을 묶어 학교명·공식 과정명과 전체 사업 기간을 표시하고 학교별 기간은 생략합니다. 학교별 날짜는 공통 원본과 이력 탭에 그대로 보존합니다. 원본 사업·학교 항목이나 전체 경력 수는 늘리지 않습니다.

기존 `teaching` 항목의 `details` 배열에 학교·업체(`title`), 활동월(`start`, `end`), 역할 ID(`role`), 커리큘럼(`curriculum`)을 기록합니다. 경력 탭에서 각 사업 제목 옆 `+` 버튼으로 세부 이력을 펼칩니다. 다시 누르면 `−`에서 `+`로 돌아오며 접힙니다. 키보드 Enter·Space도 지원합니다. 홈과 PDF는 사업별 과정과 해당 학교를 요약합니다. `note`는 선택 항목입니다. 사업에 속하지 않는 개발·프로젝트 경력은 `otherExperience`에 별도로 기록합니다. `group: "activities"`인 해커톤·42서울·구름 K-Digital 수료는 기타 활동으로 분리합니다. 테드의 프론트엔드 개발과 만렙게임즈의 게임기획은 경력 항목에 모으며, 각 역할과 기간은 구분해 유지합니다. 내부 기본 분류 ID인 `development`는 경력 제목으로 표시합니다. 홈·경력 탭·CV가 같은 분류를 사용합니다.

교육 이력은 분야별 소제목 없이 하나의 목록으로 표시합니다. `teaching_history_records()`가 사업·운영기관별 고유 원본을 완료월 내림차순으로 정렬하며, 같은 완료월이면 시작월 내림차순으로 표시합니다. `teachingGroups`와 학교별 주제·트랙은 원본 메타데이터로 유지하지만 화면 분류에 사용하지 않습니다. `otherExperience`는 경력과 기타 활동으로 구분합니다.

디지털새싹과 엘리스 SW동행은 `courses`의 `classifyDetails` 및 학교별 `details[].group`을 사용합니다. 실제 내용이 확인된 복수 분야 과정은 `details[].tracks`로 나눕니다. 원본 사업·학교 이력은 한 번만 저장합니다. `teaching_records()`는 모든 원본을, `teaching_history_records()`는 현재 활동·경력에 연결된 항목을 제외한 교육 이력을 반환합니다. 상세 웹에는 모든 트랙의 제목·커리큘럼을 표시하고, CV는 같은 사업·운영기관 안에서 공식 과정명과 학교·역할이 일치하는 경우에만 묶습니다. 전체 경력 수는 고유 원본 개수이며 분야별 수를 합산하지 않습니다.

한 학교의 여러 트랙에서 `start`·`end`를 생략하면 확인된 학교 전체 활동기간만 표시합니다. 확인되지 않은 트랙별 기간·시수는 만들지 않습니다. `group: null`인 상세도 임의 분류하지 않고 원본과 통합 목록에 유지합니다. 공개 데이터에는 계약서·계좌·학생 정보나 비공개 증빙 링크를 넣지 않습니다.

확인된 활동월만 사용하고 월이 불명확하면 연도만 적습니다. 배정·제안만 확인된 활동이나 비공개 증빙 링크는 공개 데이터에 포함하지 않습니다.

## 생성과 점검

웹 생성에는 Python 표준 라이브러리만 있으면 됩니다. 펼침·접힘 UI 회귀 테스트에는 Node.js를 사용합니다.

```sh
python3 scripts/build.py --site-only
python3 -m unittest discover -s tests
node tests/test_ui.js
node tests/test_navigation.js
```

CV까지 함께 갱신하려면 `reportlab`을 설치하고 `assets/fonts`에 포함된 Nanum 글꼴을 사용합니다. 다른 글꼴 폴더는 `CV_FONT_DIR`로 지정할 수 있습니다.

```sh
python3 -m pip install -r requirements.txt
python3 scripts/build.py
```

완성 PDF의 쪽 수·내용·내장 글꼴 검사까지 실행하려면 `pypdf`도 설치합니다. 이 패키지가 없으면 해당 검사는 건너뜁니다.

```sh
python3 -m pip install pypdf
python3 -m unittest discover -s tests
```

현재 국문 CV는 **2쪽**, 경력기술서는 **4쪽**, 영문 CV는 **3쪽**입니다. 명조 제목과 NanumGothic 본문 글꼴을 PDF에 내장하며, 글꼴과 라이선스는 저장소에 함께 보관합니다. 국문 PDF는 별도 편집·렌더 검토 후 교체하며, 기본 빌드에서는 덮어쓰지 않습니다.

기본 PDF 출력 위치는 `assets/`입니다. `CV_OUTPUT_DIR`로 다른 폴더를 지정할 수 있습니다. 생성 결과가 같으면 파일을 다시 쓰지 않으며 PDF 생성 시각 때문에 불필요한 변경이 생기지 않습니다. 데이터 수정 후에는 원본과 생성된 HTML·PDF를 함께 커밋합니다.

`scripts/layout-check.html`은 실제 사이트를 320·375·430px 프레임에서 확인하는 개발용 페이지입니다. 검색 제외(`noindex`) 상태이며 사이트 메뉴에 노출되지 않습니다.

웹은 승인된 CV의 에디토리얼 톤을 따릅니다. 흰 바탕, 네이비·차콜 글자, 얇은 카멜 구분선, 차분한 세이지 날짜를 사용하고, 민트·베이지는 표 머리글·연구 태그·학습 자료 안내에만 절제해 적용합니다. 이름과 큰 제목은 NanumMyeongjo Bold, 본문은 NanumGothic을 로컬 글꼴 파일로 표시하며 `font-display: swap`을 사용합니다. 홈은 상단 전폭 프로필 아래 현재 활동과 학위·자격을 나란히 배치하고, 연구와 전체 경력은 전폭으로 보여줍니다. 모바일에서는 한 열로 쌓고 현재 활동을 항상 표시합니다.

교육 내용에는 반복되는 일반 강사·주강사 표기를 표시하지 않습니다. 보조강사·PBL 퍼실리테이터·NCS 확인강사는 구분해 표시합니다. 워크숍은 공식 과정·대상·교육 내용만 표시하고 역할 표기는 생략합니다. 운영자가 보낸 수정 PPT를 강사의 제작 실적으로 잘못 귀속하지 않습니다. 논문 저자 표기는 각 원문의 이름·하이픈에 맞춘 논문별 재정의를 지원합니다.

`tests/test_design.py`에서 텍스트 4.5:1·조작 테두리 3:1 대비, 글자 크기, 표 구조와 반응형 규칙을 검사합니다. 실제 브라우저 시각 점검은 별도로 수행해야 합니다.

- `scripts/build.py`: 전체 생성 명령
- `assets/site.js`: 탭, 접기, 인용, 언어 전환을 각각 독립된 초기화 함수로 구성

언어를 추가할 때는 `languages`에 코드·이름·국기 경로를 넣고 같은 키를 가진 번역 파일과 데이터 번역을 추가합니다. 언어 전환, 접근성 안내, CV 연결은 이 설정에서 생성되므로 JavaScript에 언어별 조건문을 추가할 필요가 없습니다.


구름 K-Digital Training 자연어 처리 과정 수료는 기타 활동에 한 번만 표시합니다. 확인된 연도인 `2022`를 사용하며, 서로 맞지 않는 월 단위 자료에서 정확한 시작·종료월을 추정하지 않습니다.

외주 개발은 확인된 작업기간을 표시하고 계약기간·출시 완료로 확대하지 않습니다. 졸업프로젝트 KimAnNa는 확인된 2018년 활동만 표시하며, 검증되지 않은 전체 시작·종료월이나 팀장 역할을 추정하지 않습니다. 선택적인 `otherExperience[].url`은 HOME·이력·CV에서 프로젝트 제목 링크로 사용합니다.

경력의 역할·기간만 확인된 경우 `description`을 생략할 수 있습니다. 추가 설명이 없는 항목에는 빈 펼침 버튼을 만들지 않습니다.

확인된 학교별 실제 수업명은 `details[].programTitles` 또는 트랙의 `programTitles`에 기록합니다. `school_program_groups`가 동일한 수업명과 학교를 묶어 홈·이력·CV에 공통 표시합니다. 일부 기간에만 확인된 수업명은 `verifiedTeachingStart`·`verifiedTeachingEnd`로 범위를 보존하고 상세 이력에서만 표시합니다. CV에는 학교별 기간을 출력하지 않습니다. 정식 수업명이 확인되지 않은 학교에는 다른 학교의 수업명을 빌려 붙이지 않습니다.

### 검증된 교육 문맥과 수행 요약

- `courses[].client`와 `teaching[].audience`는 교육 대상, `program`은 사업/프로그램, `title`은 실제 과정명으로 구분합니다. 확인된 `teaching[].operator`만 운영기관으로 명시하며, 사업과 운영은 가운데, 교육 대상과 과정은 오른쪽에 표시합니다. 계약상대 법인과 비공개 근거는 공개 자료에 넣지 않습니다.
- 모든 원본 교육 기록에 간단한 `summary`를 두고 HOME·이력·CV에서 공통으로 사용합니다. 이전 분야별 `groupSummaries`는 보존하고 통합 화면에서는 전체 사업 요약을 사용합니다. 학교별 트랙 내용은 상세에 빠짐없이 남깁니다.
- 파주 교육은 `activeMonths`로 2026.05·2026.07을 표시하여 6월 연속 수업으로 오해하지 않게 합니다.
- 엘리스 총괄의 2023.01은 실제 첫 강의/연속 고용기간이 아닌 선발·온보딩입니다. `periodBasis`와 `periodLabel`로 날짜 성격을 원본에 보존하되, 모호한 포괄행은 `display: false`로 표시하지 않습니다. 개별 교육 이력은 유지합니다.
- 42서울은 라피신 참가(2020.07–08)와 본과정 Cadet(2020.09–2021.11)을 구분합니다.
- 상인천중학교는 2024.11 온라인 Orange3 기초·SDGs 프로젝트 주강사 기록만 추가했습니다. 회귀·분류 수업을 포함하지 않으며, 계약·배정만 확인된 다른 학교는 완료 이력에 추가하지 않았습니다.

### 중복 없는 활동과 교육 대상·과정 요약

- `current_role_records()`는 표시 대상인 진행 중 활동만 조회합니다. `teaching_history_records()`는 그 연결 원본과 경력에서 묶은 `teachingAssignments`를 교육 목록에서 제외합니다. 종료일을 확정하면 자동으로 현재 활동에서 빠지고 교육 이력에 다시 나타납니다. 원본 14개 강의·31개 세부 기록은 삭제하지 않습니다.
- 현재 활동은 원본 수행 요약을 함께 표시하고 웹의 세부 펼침에서 기존 수업별 기간·내용을 확인할 수 있습니다. 모든 펼침 ID는 유일하며 이력 탭 밖에서도 같은 키보드/언어 동작을 사용합니다.
- 학교 수업 요약은 학교명을 먼저 강조하고 실제 공식 수업명을 함께 표시합니다. `school_program_groups()`는 같은 운영기관·사업·공식 과정 안에서만 학교명을 묶습니다. 한동 A/B처럼 정식 과정명이 확인되지 않은 항목에는 다른 학교의 과정명을 옮기지 않으며, 원본 반별 기간과 역할·내용은 웹 상세에 남깁니다.
- 민코딩은 경력 한 항목에서 T아카데미 강사와 삼성 SDS 보조강사 출강을 묶고, 원본 교육 기록을 삭제하지 않습니다. 확인된 연도 2025만 표시하며 고용형태를 추정하지 않습니다.
- 엘리스그룹과 에듀코어센터가 각각 운영한 SW동행은 서로 다른 원본 ID와 행으로 유지합니다. 강사 사전 원격교육은 확인된 2024년 3기 디지털새싹 사업과 행사명을 사용합니다.
- 고색고등학교는 운영 프로그램 `주문형강좌`, 과목 `정보과학`으로 구분하며 확인된 기존 활동월을 유지합니다.

### 역할이 구분된 사업 관계

`teaching[].relationships`는 검증된 사업 관계만 역할 ID·한영 이름·요약 표시 여부로 기록합니다. 소관부처, 사업 관리, 전담기관, 지원, 사업기관, 분과 주관, 운영, 소속을 서로 바꾸어 쓰지 않습니다. 디지털새싹의 엘리스그룹은 사업 주관·운영, 2025 SW동행의 동아사이언스는 AI 분과 주관, 에듀코어센터는 교육 운영으로 구분합니다. 엘리스 SW동행에는 확인되지 않은 주관 표기를 추가하지 않습니다. 사업 전체와 개별 강좌의 행사 주최·주관도 구분합니다.

CV와 웹 요약은 프로그램·기관명을 간단히 표시하며, 주관·운영·지원 등 정확한 관계는 웹 세부 펼침에서 확인할 수 있습니다. `teaching_display_columns()`는 읽기 쉬운 요약, `teaching_detail_context()`는 역할을 구분한 상세 정보를 제공하며 공통 원본의 사실은 바꾸지 않습니다. 계약 법인·위촉증명서·개인 계약일과 사적 근거는 별도 비공개 검증자료에 보존하며 공개 원본에 복사하지 않습니다. 코더랜드는 확인된 프리랜서 역할을 표시하되 실제 출강 시작인 2023.03을 유지합니다. 민코딩 출강은 행사 운영기관 확정 대신 소속 관계로 표시합니다.
