# 서울·수도권 AI 박사과정 지원 현황

[ys-faculty]: https://swedu.yonsei.ac.kr/yonseisw/intro05.do

최종 갱신: **2026-09-20 (Asia/Seoul)** · 대상: **2027학년도 전기**  
관리 원본: `Snow0821/Snow0821.github.io` / `main` / `admissions/README.md`

서울을 우선하고, 수도권은 연구 적합성이 강한 경우에 포함한다. 독립 박사과정과 진학으로 이어질 수 있는 연구인턴·RA·공동연구를 함께 검토한다. 연구 기준은 **이산 학습, integer-only/floatless, neuro-symbolic, neuromorphic**이며, OSLGN의 operand/operator 선택·STE 경험과 연결한다.

**표기:** 확인 = 이번에 원문 확인 / 예정 = 원문에 예정으로 표시 / 재확인 = 기존 기록 또는 접근 제한으로 현재 확정 불가. 연구 적합성·우선순위·권장 행동은 공개 연구를 바탕으로 한 판단이다. 모집 공고는 교수 개인의 TO나 합격 가능성을 보장하지 않는다.

### 연세대 HAI Lab — Jaeyong Chung / 정재용

- **서울 신촌.** [연구실][hai]이 이메일 지원자를 모집 중이며, 연락처는 `jyc@yonsei.ac.kr`. 개인의 2027 박사 TO는 미확인.
- **연구 근거:** [공식 논문 목록][hai-pubs]의 *Two-Stage Unit Tying for Simplifying Differentiable Logic Gate Networks* (ICML 2026), GSRQ (ICML 2026). 논리 게이트 선택·양자화 연구가 OSLGN과 직접 연결된다. 완전한 integer-only 학습을 이미 수행한다고 해석하지 않는다.
- **제안할 연구:** OSLGN의 연결·연산자 선택과 unit tying을 결합한 정수/저정밀도 logic-gate learning.

### 고려대 Efficient Machine Intelligence Lab — Youngeun Kim

- **서울 성북구.** [공식 Join 페이지][emi-join]에 신설 연구실 첫 구성원, fully funded PhD 및 연구인턴 모집 명시. `youngeunkim@korea.ac.kr`; 페이지 내 지원서에 CV·성적표·짧은 연구관심서 제출.
- **연구 근거:** [연구 분야][emi-research]의 SNN 학습·ANN-to-SNN·in-memory computing·양자화. [논문 목록][emi-pubs]의 *MD-SNN* (DATE 2026), *Task Vector Quantization for Memory-Efficient Model Merging* (ICCV 2025).
- **제안할 연구:** 정수/저정밀도 surrogate-gradient SNN, quantized task-vector를 활용한 network merging/branching. 기존 논문이 동적 merging/branching 자체를 검증한 것은 아니다.
- **09-18 전형요건 확인:** [2027 전기 공식 안내][ku-schedule]에서 박사 공통서류로 학부·석사 학위·성적증명서, 연구계획서, 석사학위논문개요(논문이 없으면 사유 기재)를 요구한다. 최근 5년 대표 연구실적은 석사논문을 제외하고 최대 3편까지 제출 가능하므로 IJCNN 2026 채택 논문을 핵심 증빙으로 쓰기 좋다. 공인영어는 인공지능학과에서 선택 제출 시 평가에 반영되며, **2024-09-29 이후 응시하고 10-07 접수마감 전 점수가 확정된 성적**만 유효하다. - **신분·자격:** 석사 졸업자를 유급 연구원/RA/연구 인턴으로 받는지, 재학 요건이나 박사 지원·입학 의무가 있는지.
- **근무·보수:** 시작일·최소 기간·계약 연장 조건, 주당 참여 시간, 상주/원격, 실제 근무지, 급여·지급 기준·보험.
- **연구 내용:** 맡을 프로젝트와 지도 방식, 구현/데이터 처리 대 알고리즘 연구 비중, 기존 OSLGN·정수학습 주제를 이어갈 수 있는지.
- **준비 자료:** CV·OSLGN 논문·코드 저장소·참여 가능 기간을 기본으로 준비. 성적표는 요구한 곳에 제출하고, 연구실별 연결점과 첫 실험을 1쪽으로 정리.

**관리:** 이후 신규·변경 기회를 이 절의 같은 행에 갱신한다. 고정 마감 채용은 마감일을 명시해 상시 모집과 구분하고, 기존 입시 후보와 중복돼도 참여 신분·자격·보수는 별도로 관리한다.

## 지원 전 공통 확인

- **연세대 중복지원:** 한 학기에 한 전형·한 학과만 지원. HAI의 두 경로와 SCLAB·ICL 사이에도 적용. [요강][ys-guide] p.5.
- **연세대 영어:** 컴퓨터과학과는 TOEFL·TOEIC·TEPS를 제출 시 반영하며 IELTS는 미인정. 인공지능학과·AX반도체공학과·지능형디스플레이공학과는 공인영어 평가 미반영. 제출하는 경우 2024-12-04 이후 응시 성적 기준. [요강][ys-guide] p.4, 27.
- **연세대 서류·장학:** 학부·석사 학위/성적·학업연구계획서 준비, 연구실적 증빙 활용. BK21 박사 월 160만 원 이상은 **참여학생 선발 조건**이며 자동 수혜가 아님. 세부 제출 규격과 학과 추가서류는 [요강][ys-guide] 확인.
- **서울대 영어:** AI대학원 TOEFL iBT 구체계 96점 또는 개정 체계 5.0, TEPS 327점 이상. 응시 시점에 따른 체계와 원서 마감 기준 2년 이내 인정 여부 확인. [요강][snu-guide] p.10~11. 점수가 높아도 유효기간이 지나면 충족으로 표시하지 않음.
- **모든 후보:** 독립 박사 가능 여부, 교수별 TO, 지도 방식, 연구 주도권, 등록금과 생활비 각각의 금액·지급 시점·보장기간 확인. 공개된 지원금끼리 임의로 합산하지 않음.
- **면담 자료:** CV, 학부·석사 성적표, IJCNN 2026 OSLGN 논문/채택 증빙, 연구실별 연결점과 첫 실험을 담은 1쪽 메모. 실제 상담·회신·지원 진행은 아래에 기록.

현재 이 파일에 확인된 교수 연락·회신·설명회 참석·원서 제출 기록은 없음. 이후 `날짜 | 후보 | 실제 행동·회신 | 다음 행동` 형식으로 간결하게 추가한다.

## 유지보수

- 이 파일을 현재 상태의 원본으로 유지한다. 날짜별 복사본·연구실별 파일을 늘리지 않는다.
- 상시 연구원·인턴 기회는 별도 절에서 관리한다. 석사 졸업자 참여 가능 여부, 실제 모집 신분, 상시 명시 여부, 급여·기간·근무지와 입학 의무를 따로 확인한다. 학부생 인턴·postdoc·박사 장학 조건을 석사후 연구원 조건으로 전용하지 않는다.
- 새 공고와 기존 후보의 변경을 원문으로 대조하고, 해당 행·문단을 갱신한다. 재확인 실패를 모집 종료로 바꾸지 않는다.
- 공식 마감과 권장 연락 시점을 구분한다. 지난 설명회는 종료로 표시하고, 과거의 임의 권장일을 현재 마감처럼 재사용하지 않는다.
- 동일 연구실·다른 전형·재게시를 구별해 중복을 합친다. 사용자 메모와 실제 행동 기록을 보존하며 추정으로 완료 처리하지 않는다.
- 의미 있는 변경에만 갱신일·변경 요약과 Git 커밋을 남긴다. 변경이 없으면 날짜만 바꾸는 커밋을 만들지 않는다.
- 최근 변경 요약은 5개 이내로 유지하고, 과거 상세 변경은 Git 이력에서 확인한다.
